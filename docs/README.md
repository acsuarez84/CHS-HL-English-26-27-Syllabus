# Course texts (PDFs)

Drop PDFs of the literary works here using these exact filenames. The site
checks for each file at build time: if it is present, the work links to your
PDF; if it is absent, the work falls back to a verified public source.

| Filename | Work |
|----------|------|
| `tunnel.pdf` | *The Tunnel* — Ernesto Sabato |
| `hour-of-the-star.pdf` | *The Hour of the Star* — Clarice Lispector |
| `othello.pdf` | *Othello* — Shakespeare |
| `eliot-poems.pdf` | Selected Poems — T. S. Eliot |
| `woman-in-the-dunes.pdf` | *The Woman in the Dunes* — Kōbō Abe |
| `mansfield-stories.pdf` | Selected Short Stories — Katherine Mansfield |

After adding files, re-run the site build so the links pick them up.

**Copyright note.** *Othello* and Mansfield are public domain. Sabato,
Lispector, Abe and Eliot are still in copyright — host those only if the
district's license or fair-use policy covers classroom distribution, and keep
the repository private if that is the condition of use.
